## Proyecto destacado

### Panel de Operaciones

Un panel que recibe, por sí solo, todo lo que produce un agente de IA a lo largo del día: rutinas programadas, análisis, informes, integraciones y despliegues. Cada publicación queda registrada con fecha y hora, y el panel construye la vista completa por sí solo a partir de un manifiesto JSON.

El agente es realmente autónomo. Ejecuta las rutinas programadas, publica por su cuenta en una red social, revisa mensajes y genera un informe semanal sin intervención humana.

**La muestra pública está en marcha y cualquiera puede abrirla:**
[central_operacoes_demo](https://github.com/JonasFilhoDev/central_operacoes_demo) · [abrir el panel](https://jonasfilho1985.github.io/central_operacoes_demo/)

El código está abierto en esa muestra. La instancia real es privada, y su README explica por qué.

**Tecnologías:** HTML, CSS y JavaScript sin framework · Python y Bash en los scripts · nginx con TLS y autenticación básica · Git para el versionado · Ubuntu Server en Oracle Cloud

En la parte de integraciones, trabajo con una capa de catálogo que da acceso a 1.000 integraciones (40.702 herramientas). Verifiqué cuatro cuentas leyendo datos reales, no por un indicador de estado: GitHub, Gmail, Drive y LinkedIn.
