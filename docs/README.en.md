## Featured project

### Operations Dashboard

A panel that receives, on its own, everything an AI agent produces during the day: scheduled routines, analyses, reports, integrations and deployments. Every publication is recorded with a timestamp, and the panel builds the whole view by itself from a JSON manifest.

The agent is genuinely autonomous. It runs the scheduled routines, publishes to a social network on its own, checks messages and produces a weekly report with no human intervention.

**The public showcase is live and anyone can open it:**
[central_operacoes_demo](https://github.com/JonasFilhoDev/central_operacoes_demo) · [open the panel](https://jonasfilho1985.github.io/central_operacoes_demo/)

The code is open in that showcase. The real instance is private, and its README explains why.

**Stack:** HTML, CSS and JavaScript with no framework · Python and Bash for the scripts · nginx with TLS and basic auth · Git for versioning · Ubuntu Server on Oracle Cloud

On the integration side, I work with a catalogue layer that exposes 1,000 integrations (40,702 tools). I verified four accounts by reading real data, not by a status indicator: GitHub, Gmail, Drive and LinkedIn.
